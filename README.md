# Temperature Controlled Fan Using Arduino

## Project Overview
This project is an Arduino-based automatic fan speed controller that adjusts fan speed according to the surrounding temperature.

The system uses a DHT11 temperature and humidity sensor to measure environmental conditions. Arduino UNO processes the readings and controls the DC fan speed using PWM signals.

A 16x2 LCD displays temperature, humidity, and fan status.

## Components Used
- Arduino UNO
- DHT11 Temperature and Humidity Sensor
- DC Fan
- 2N2222 Transistor
- 16x2 LCD Display
- Breadboard
- Connecting Wires

## Working Principle
1. DHT11 measures temperature and humidity.
2. Arduino UNO processes sensor readings.
3. PWM signals control the fan speed.
4. A transistor drives the DC fan.
5. LCD displays temperature and fan status.
